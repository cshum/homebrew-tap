# homebrew-tap

```sh
brew install cshum/tap/imagor-mcp
```

Formulae for cshum projects. `Formula/imagor-mcp.rb` is generated by
`scripts/render.py` from the latest [imagor-mcp](https://github.com/cshum/imagor-mcp)
release and refreshed by a scheduled workflow, so it tracks releases without anyone
editing it by hand.
